# en-r014: an addition that looks exactly like an update

The trap for the supersedes metric. Same person, same meeting, same sentence
frame, five days apart: a judge keying on recency plus surface similarity reads
this as "the section changed" and supersedes the earlier commitment.

It did not change. Ana owes both sections. A wrong supersession here closes the
validity interval on a live commitment and Cogeto stops surfacing it, which is
the same class of harm as a false merge: a fact the user still needs quietly
stops existing.

Scored twice: under contradiction precision (a `contradicts` flag here is a
false positive) and under supersedes accuracy (a supersession verdict here is a
false positive, counted in the denominator).
