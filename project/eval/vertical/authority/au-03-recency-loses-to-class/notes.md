# au-03: when recency and authority disagree

**PENDING. Not loaded by the harness. PARTLY SYNTHETIC.**

**Signal under test.** Document class beating recency.

**Why this is the case that matters.** In every real supersession pair in this
corpus, the more authoritative document is also the more recent one, so
Cogeto's recency rule reaches the right answer for the wrong reason and no
measurement can tell the difference. This case is the one that separates them,
and it cannot be built from the material sourced for item 6.4.

**What sourcing it would take.** A document set where a low-authority document
(a supplier datasheet, a tender annex, a supplier declaration) is published
after a high-authority one (a regulation, a harmonised standard) and states
something incompatible with it. That is common in practice and it is findable;
it was not found inside the time this unit had, and saying so is better than
constructing it.
