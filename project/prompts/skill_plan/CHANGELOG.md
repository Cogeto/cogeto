# skill_plan — changelog

## v0001 — 2026-07-25 (Priority 7, decision 0059)

Initial version. Plans the 3 to 6 web queries of the research-brief skill on
the pipeline tier from the subject plus the memory context (recorded facts and
open loops). Minimisation is built into generation (decision 0059 ruling 3):
the subject's name stays (researching it is the point), third-party names,
internal details and occasions never enter a query, and each query carries a
one-sentence reason the user reads at the plan gate. The gate remains the
guarantee — every query is shown for approval, editable and removable, before
anything leaves.
